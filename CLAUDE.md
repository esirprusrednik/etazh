# Этаж — правила для правок

- Любое изменение, заметное пользователю, записывай в `public/changelog.json` под сегодняшней датой по Москве (YYYY-MM-DD).
  Если запись за этот день уже есть — дополняй её, новый день не заводи. Свежий день — первым в массиве.
- Три списка: `new` (новое), `better` (стало удобнее), `fix` (починили). Одна строка — одна мысль, языком пользователя, без внутренней кухни (тесты, скрипты, миграции не пишем).
- Новая функция или меню — допиши пункт в туториал `public/js/guide.js` (раздел той вкладки, где она живёт).
- После правки интерфейса поднимай номер кэша в `public/sw.js`, новые файлы добавляй в `files.txt`.
- Перед коммитом — `npm test`. Деплой не делаем: его запускает владелец через go.sh.
