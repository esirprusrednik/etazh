# Этаж — пилот

Это веб-приложение (PWA) для коллег. Его открывают в браузере телефона и ставят иконкой на экран «Домой». В нём есть:

- **банды** с чатом и зовами («на кофе», «ты где?», «перезвони» и другие) и пуш-уведомлениями;
- **отметка в офисе** и оценка загрузки столовой;
- **сигналы офиса**: холодно, еда на кухне, кофе закончился;
- **зёрна и лавка**.

На сервере нет внешних зависимостей: только Node.js 22 и его встроенная SQLite. `npm install` не нужен.

---

## 1. Что хранится на сервере

| Данные | Как хранится |
|---|---|
| Рабочая почта | **Не хранится.** В базе лежит только HMAC-SHA256 отпечаток с секретом `EMAIL_PEPPER`. Почта нужна лишь на секунду, чтобы отправить письмо со ссылкой. В логах её тоже нет. |
| Никнейм, аватар, «обо мне» | Заполняет сам пользователь. ФИО, должностей, отделов и телефонов нет. |
| Отметки в офисе | Удаляются на следующий день. |
| Отметки в столовой | Через сутки обезличиваются, через 30 дней удаляются. |
| Сообщения банды | Удаляются через 24 часа. |
| IP-адрес | В базу не пишется. Используется только в памяти для защиты от перебора. Caddy пишет в лог только ошибки. |
| Пуш-подписки | Сохраняются. Содержимое пуша шифруется ключом устройства, так что Apple и Google видят только шифротекст. |

Пользователь может удалить аккаунт кнопкой в профиле, и его данные удаляются сразу.

> ⚠️ Отпечаток почты — это всё равно персональные данные: по нему можно проверить, зарегистрирован ли конкретный человек, если знать `EMAIL_PEPPER`. Поэтому тезис «кроме email, ничего» по 152-ФЗ не значит «персональных данных нет». См. раздел 5.

## 2. Что понадобится

1. **VPS в России.** Хватит 1 vCPU, 1–2 ГБ RAM и 20 ГБ диска: Timeweb Cloud, Selectel, Yandex Cloud, REG.RU и т. п. Это примерно 300–700 ₽/мес. Сервер в РФ нужен из-за требования о локализации (ст. 18 ч. 5 152-ФЗ).
2. **Домен и A-запись** на IP сервера, например `etazh.ваш-домен.ru`.
3. **SMTP для писем со ссылкой входа.** Подойдёт транзакционный сервис (Unisender Go, SendPulse, Яндекс 360 для домена, Mail.ru для бизнеса). Для домена отправителя нужно настроить **SPF, DKIM и DMARC** — без них письма на корпоративную почту почти наверняка уйдут в спам или будут отрезаны.
4. Docker и Docker Compose на сервере.

> ⚠️ **Главный риск запуска — доставка писем на @mts.ru.** Корпоративный почтовый шлюз может резать письма с незнакомых доменов, особенно со ссылками. **Прежде чем звать людей, отправьте себе 5–10 тестовых писем.** Если они не доходят, остаются два варианта: договориться с ИБ о белом списке домена или вернуться к варианту на внутреннем контуре.

## 3. Запуск

```bash
# на сервере
git clone <ваш репозиторий> /opt/etazh && cd /opt/etazh   # или скопируйте папку
cp .env.example .env
node scripts/gen-secrets.js >> .env   # или: docker run --rm -v "$PWD":/a -w /a node:22-alpine node scripts/gen-secrets.js >> .env
nano .env                              # домен, SMTP, ADMIN_EMAILS; удалите пустые дубли строк EMAIL_PEPPER/VAPID_*
docker compose up -d --build
docker compose logs -f app             # должно быть: «Этаж слушает :3000 … почта: smtp, пуши: вкл»
```

Откройте `https://ваш-домен` на телефоне. Caddy получит сертификат сам за пару минут после старта.

**Обязательно:**

- Сохраните `EMAIL_PEPPER` отдельно, например в менеджере паролей. Если его потерять, все аккаунты «отвяжутся» от почты.
- Настройте бэкап базы, добавив в `crontab -e`:
  ```
  15 3 * * * /opt/etazh/scripts/backup.sh >> /var/log/etazh-backup.log 2>&1
  ```
  Копии складываются в `backups/`, хранятся последние 14. Раз в неделю уносите их с сервера.
- Закройте на сервере всё, кроме 22, 80 и 443 (`ufw`). Вход по SSH — только по ключу.

**Обновление:** `git pull && docker compose up -d --build`. Схема базы мигрирует сама.

### Локально, для разработки

```bash
npm run dev          # http://localhost:3000, письма не отправляются — ссылка и код видны на экране
npm test             # 4 модульные + 21 сквозная проверка API
```

## 4. Как устроено

```
server/
  index.js     HTTP-сервер, статика, заголовки безопасности (CSP, no-referrer), задачи очистки
  api.js       все эндпоинты: вход, офис, столовая, банды, чат, зовы, сигналы, лавка, жалобы, админка
  db.js        схема SQLite и стартовые офисы (места в столовых — заглушки, калибруются в админке)
  catalog.js   справочники: зовы, сигналы, лавка, начисления зёрен — меняются без миграций
  mailer.js    минимальный SMTP-клиент (SSL/STARTTLS, AUTH LOGIN)
  webpush.js   Web Push: VAPID + шифрование aes128gcm
public/        PWA: index.html, js/app.js, sw.js, manifest, иконки, privacy.html, rules.html, admin.html
tests/         unit.js (пуши, SMTP, модерация) и smoke.js (сквозной сценарий API)
```

**Вход.** Человек вводит почту на @mts.ru (домен проверяется на сервере) и получает письмо со ссылкой и 6-значным кодом. Ссылка и код живут 15 минут и работают один раз. Код нужен для iPhone: установленное приложение не видит вход, сделанный в Safari. Сессия хранится 90 дней в cookie с флагами HttpOnly, Secure и SameSite=Lax.

**Столовая.** Оценка строится по закону Литтла: поток отметок за 15 минут × среднее время обеда ÷ доля сотрудников с приложением. Очередь показывается ступенями: нет / ≈5 / ≈10 минут. Среднее время обеда считается само по кнопке «Поел». **Долю пользователей и число мест надо подкрутить в админке** по реальным наблюдениям в первую неделю.

**Модерация.**
- Стоп-лист корней с защитой от подмены букв латиницей.
- Нельзя писать @ в названиях.
- Не больше 3 зовов в час.
- После 3 жалоб контент скрывается. Модераторы — адреса из `ADMIN_EMAILS`, страница `/admin.html`.

### Что из ТЗ сделано, а что нет

| Есть | Нет (следующий шаг) |
|---|---|
| Вход по @mts.ru (ссылка + код), никнейм, аватар-конструктор, «обо мне» | Квесты с подтверждением от коллеги |
| Статусы: «из дома», «болею» (до 14 дней), «в отпуске» (график или вручную), «отлыниваю 😏» (только сам). Приоритет: отметка → отпуск → болею → ручной → план. Нет статуса после 11:00 — нейтральная шутка («в астрале»). В отпуске и на больничном зовы не присылают пуши | |
| Отметка в офисе до 19:00, видно только свой офис | Ачивки по тирам (обычные / редкие / легендарные) |
| Столовая: статус, очередь ступенями, тренд, совет | Подарки коллегам |
| Банды: залог 50 с возвратом при 3 участниках, ссылка-приглашение, чат 24 ч | Дни рождения в ленте |
| 8 зовов с ответами, пуши, тихие часы 19–9 | QR-код на ресепшене для отметки |
| Сигналы офиса с подтверждением и пушем отмеченным в офисе | Статистика банд (от 5 человек) |
| Лавка: статусы, рамки, корона, знамя и девиз банды | Сезоны и лимиты лавки по сезонам |
| Жалобы, модерация, сигналы для АХО в админке | Выгрузка своих данных (ст. 14 152-ФЗ) — пока по запросу на почту |
| Установка PWA, баннер «Установи на телефон», офлайн-оболочка | |

Приветственный бонус — **50 зёрен** (в прототипе было 30). Иначе в первый день пилота никто не сможет создать банду, а без банд приложение пустое. Значение задаётся в `WELCOME_BEANS`.

## 5. Перед тем как звать коллег — чек-лист

Сам код это не закрывает, но без этих пунктов запуск рискованнее, чем кажется.

- [ ] **Оператор персональных данных — вы лично.** Заполните `[поля]` в `public/privacy.html` и покажите текст юристу.
- [ ] **Уведомление в Роскомнадзор** (ст. 22 152-ФЗ). Исключения из обязанности узкие; уточните у юриста, подпадаете ли вы под них. Подача онлайн на pd.rkn.gov.ru, бесплатно.
- [ ] **Письменное «ок» от руководителя и ИБ.** Рассылка корпоративным адресам со стороннего домена и приложение «для сотрудников МТС» без согласования могут закончиться претензиями, даже если данных почти нет. Удобная рамка — оформить как гипотезу для пилота, а не как самодеятельность.
- [ ] **Не используйте логотип и фирменный стиль МТС.** В приложении их нет, и не добавляйте их.
- [ ] Тест доставки писем на @mts.ru (раздел 2).
- [ ] Бэкапы настроены, `EMAIL_PEPPER` сохранён отдельно.
- [ ] В админке выставлены реальные места в столовых.
- [ ] Пилот на одну команду (10–30 человек) на 2 недели, только потом шире.

## 6. Если что-то не работает

- **Письма не приходят.** Проверьте `docker compose logs app` на ошибку SMTP и SPF/DKIM домена. Временно можно поставить `MAIL_MODE=console`: ссылки будут в логе, это подходит для теста на себе.
- **Нет пушей на iPhone.** Нужен iOS 16.4+, приложение должно быть установлено на экран «Домой», уведомления включаются в профиле изнутри установленного приложения.
- **«Сервер не поднялся».** Почти всегда причина в пустом или коротком `EMAIL_PEPPER` (нужно не меньше 32 символов). Сервер пишет причину при старте.

## 7. Быстрая установка одной командой

На чистом Ubuntu 22.04/24.04, из папки проекта:

```bash
sudo bash scripts/install.sh
```

Скрипт:
- ставит Docker, файрвол (открыты только 22, 80, 443) и fail2ban;
- отключает вход по паролю, если на сервере есть SSH-ключ;
- спрашивает домен и SMTP, генерирует секреты в `.env`;
- проверяет DNS, запускает приложение и ставит ночной бэкап.

Запускать повторно безопасно.

**До запуска нужны:** сервер с доступом по SSH-ключу, домен с A-записью на IP сервера, данные SMTP (можно позже — тогда ссылки входа будут в логе).
